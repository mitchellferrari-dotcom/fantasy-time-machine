2025 DATA UPDATE

1. Extract this ZIP.
2. Open PowerShell inside fantasy-time-machine folder.
3. Run: py -m pip install pandas requests
4. Run: py add_2025.py
5. Run: npm install
6. Run: npm run dev
7. Refresh http://localhost:3000

The Python importer fetches 2025 nflverse weekly regular-season stats, validates QB/RB/WR/TE counts, and appends them to players.json. No fabricated stats. Kicker support remains disabled.
